# STEP import corpus

Files used by the STEP screening and import tests, with what OpenCascade
reads back from each as the oracle (`expected/*.json`: per-solid volume,
bounding box and face count, in millimetres, sorted by bounding box).

| Directory | Source | Licence |
|---|---|---|
| `occt/` | Written by OpenCascade 7.8 through `generate_occt.py` in this directory: primitives, a plate with holes, fillets, a loft, revolved and extruded splines, a hollow sphere (`BREP_WITH_VOIDS`), inch/metre units, AP203/AP214/AP242 schemas, and a two-level assembly | Generated by this project (MIT OR Apache-2.0) |
| `external/as1-oc-214.stp` | The classic "as1" AP214 assembly (Datakit converter, 2008), from [STEPcode](https://github.com/stepcode/stepcode) `data/ap214e3/` | BSD-3-Clause, see `external/STEPCODE-COPYING.txt` |
| `external/red_cube_blue_cylinder.step` | Coloured AP214 part exported by Onshape's translator, from [CadQuery](https://github.com/CadQuery/cadquery) `tests/testdata/` | Apache-2.0, see `external/CADQUERY-LICENSE.txt` |

Regenerate the OpenCascade files and every oracle:

```sh
python3 -m venv venv && venv/bin/pip install cadquery-ocp==7.8.1.1.post1
venv/bin/python generate_occt.py
venv/bin/python generate_occt.py --oracle external/*.st*p
```

Only add files whose licence allows redistribution. NIST's MBE PMI test
models (public domain, written by CATIA, NX, Creo and SolidWorks) are the
next candidates.
